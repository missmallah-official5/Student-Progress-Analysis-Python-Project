# Student Progress Analysis – Python Project

## Overview
A beginner Python project that calculates students' total marks, percentages, grades, and pass/fail results. It also compares performance across multiple students and prints motivational messages. Designed to demonstrate basic Python programming, conditional statements, and simple result processing.

## Features
- Calculates percentage based on total marks
- Assigns grades (A+, A, B, C, D, Fail)
- Prints pass/fail results
- Compares performance of multiple students
- Includes motivational messages

## How to Run
1. Clone or download the repository
2. Open the Python file `student_progress_analysis.py`
3. Run the script in any Python IDE or terminal
4. Observe the results printed in the console

## Skills Demonstrated
- Python programming basics
- Conditional statements and logic
- Simple result calculation and reporting
